## 🌟 Features
- **Responsive Design:** Optimized for desktop, tablet, and mobile views, ensuring a seamless experience on any device.​

- **Interactive Menu:** Showcase our signature dishes with enticing images, detailed descriptions, and prices.​

- **Reservation Form:** Allow customers to easily book a table directly from the landing page.​

- **Smooth Animations:** Enhance user engagement with subtle animations and transitions.​

- **Social Media Integration:** Link to Savory Bites' social media profiles to increase online presence.​

- **Light and Dark Theme Support:** This feature allows users to switch between light and dark modes, enhancing readability and user experience based on individual preferences.​

## 🛠️ Technologies Used
- **HTML5:** For structuring the web content.​

- **CSS3:** For styling and layout, utilizing Flexbox and Grid systems.​

- **JavaScript:**  For interactive elements and form validation.​
